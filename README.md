# Healthcare Prior Auth Agent

An agent that reads a patient's insurance plan document and a prescription, then drafts a prior-authorization request automatically. Uses a RAG pipeline over plan documents combined with agentic drafting logic to reduce the manual effort of prior-auth paperwork.

**Who'd use it:** Health system prior-auth coordinators, payer-facing ops teams, or health-tech startups looking to automate prior-auth drafting.

**Tech stack:** React frontend, FastAPI backend, Docker.

**Status:** scaffold — this is a stub to be built out later, not a finished product. No demo link exists yet.
